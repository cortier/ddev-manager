Companion connection

Install the companion from the Cortier release package, then run its installer. DDEV and Git must already be installed.

Automatic removal works when Firefox opens the uninstall page and the cleanup service is running. The companion stays installed while other Firefox profiles are registered.

For manual removal, run the package’s uninstall.sh script. Removing the companion affects every Firefox profile using it. Your DDEV projects stay untouched.
